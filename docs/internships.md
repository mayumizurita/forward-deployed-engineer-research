## What to prioritize

1. **Build a small working system.** Pace and AiStudio explicitly value evidence of building. Show the user problem, implementation and feedback.
2. **Practice explaining a technical choice to a user.** Communication and translating unclear problems recur in the sample.
3. **Choose a technical direction.** AI workflow work and hardware integration require different preparation; use the individual briefs.

These priorities are research-based suggestions, not employer interview criteria. [Skills evidence](./skills.md).

## Before applying

Check the original posting for current deadlines, graduation windows, location, work authorization, duration and whether you must return to school. Missing details in a brief mean **not established**, not unrestricted eligibility.
