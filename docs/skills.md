# Skills & evidence

**Learn the shared foundation, then follow the stack in your target job.** “Required,” “preferred” and “described work” are different signals. The table preserves that distinction.

## Shared foundation

| Skill | Evidence from descriptions | What you could show¹ |
| --- | --- | --- |
| Programming | Palantir requires one language; Pace asks for programming experience; Revel asks for C/C++/Python | A working project with readable code |
| Problem framing | Pace describes discovery; OpenAI describes technical scoping | A short problem statement and scope decisions |
| Customer communication | Pace asks for clear communication; Palantir describes stakeholder relationships | A user walkthrough and feedback notes |
| Debugging & iteration | Revel explicitly asks for debugging; Pace describes investigating agent behavior | A documented failure, diagnosis and fix |
| Ownership under ambiguity | Pace, AiStudio and Palantir explicitly emphasize ambiguity or initiative | A decision made with incomplete requirements |

Sources: [Palantir intern](./jobs/palantir-intern.md), [Pace](./jobs/pace-intern.md), [Revel](./jobs/revel-intern.md), [AiStudio](./jobs/aistudio-intern.md), [Palantir graduate](./jobs/palantir-grad.md), [OpenAI](./jobs/openai.md).

## A manageable preparation project¹

Build one tool for a real user's small workflow. Include an integration, a way to check correctness, deployment instructions and one revision based on feedback. Choose an AI or hardware component only if it matches your target posting.

¹ Suggested portfolio evidence is the researcher's interpretation, not an employer requirement or a guarantee of interview success.
